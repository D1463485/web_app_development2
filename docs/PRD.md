# PRD - 讀書筆記本

## 1. 專案概述
### 背景與動機
在資訊爆炸的時代，許多人閱讀書籍後常常忘記重點內容，缺乏一個輕量、簡單的工具來記錄與回顧。現有的筆記軟體可能過於龐大複雜，本專案希望能提供一個專注於書籍重點與進度追蹤的輕量化閱讀工具，幫助使用者有效管理閱讀旅程。

### 目標用戶
希望能快速紀錄並檢索讀書心得的學生或讀者。

### 核心價值主張
提供一個簡單直覺的介面，讓使用者能快速記錄書籍資訊、重點語錄與個人感想，並能輕鬆追蹤閱讀進度及檢索過去的筆記。

## 2. 功能需求
以下為系統的主要功能，並以使用者故事（User Story）格式呈現：

1. **書籍存檔**
   - 作為 **讀者**，我希望 **能快速建立書名與作者清單**，以便 **整齊管理我的個人書架**。
2. **分段筆記**
   - 作為 **讀者**，我希望 **有專用區塊來記錄精采語錄與個人感想**，以便 **將閱讀時的靈感與重點妥善保存**。
3. **進度管理**
   - 作為 **讀者**，我希望 **能標記目前的閱讀狀態（例如：在讀中、已完讀）**，以便 **隨時掌握自己每本書的閱讀進度**。
4. **關鍵字搜尋**
   - 作為 **讀者**，我希望 **能利用標題或關鍵字標籤進行搜尋**，以便 **在眾多筆記中快速找到特定內容**。
5. **資料儲存**
   - 作為 **使用者**，我希望 **系統能支援本地檔案存檔（如 JSON 或 SQLite）**，以便 **確保關閉程式後我的紀錄不會遺失，且資料便於攜帶與管理**。

## 3. 非功能需求
### 技術限制
- 系統架構預計採用 **Flask + Jinja2 + SQLite**，以符合輕量化 Web 應用程式的開發需求。
- 為符合需求中提到的「支援本地檔案存檔」，可使用 SQLite 作為主要本地資料庫，或實作 JSON 檔案格式的匯出與讀取功能。

### 效能與安全考量
- **快速載入**：系統介面與搜尋功能需反應迅速，使用者操作無明顯延遲。
- **資料安全**：由於是本地存檔系統，需確保在資料寫入或程式關閉時資料不會損毀。

## 4. MVP 範圍
### Must Have (必須具備)
- 新增書籍（包含書名、作者）與書架列表顯示。
- 單一書籍的新增與檢視分段筆記功能。
- 書籍閱讀狀態標記（如：未讀、在讀中、已完讀）。
- 基礎的本地檔案儲存機制（確保資料持久化）。

### Should Have (應該具備)
- 利用標題或標籤的關鍵字搜尋功能。
- 編輯與刪除已建立的書籍或筆記。

### Nice to Have (最好具備)
- JSON 格式資料的匯入/匯出功能，方便使用者備份。
- 閱讀進度百分比或頁數追蹤。
- 根據狀態（如在讀中、已完讀）進行列表篩選。
